# Real-browser demo capture

Manual GitHub workflow runs the real static app in Chromium on its isolated runner. It records a continuous 120-second scripted interaction using the bundled synthetic example. It asserts 5/6 coverage, correction of a changed spacing, 6/6 after adding the omitted pair, retention of the unrelated slot-width warning, and actual downloaded JSON contents. It does not upload/import data, use accounts/API models or claim a human user study.

`captions.srt` is a proposed silent-film caption track. Review the actual resulting video, pacing, legibility and synchronization before calling it a judge-ready demo. A successful CI test alone is not perceptual review. Raw video, screenshots, audit and export are retained as a short-lived Actions artifact. Source publication does not mean contest submission.
